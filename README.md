# WordPress Temaları

Farklı sektörler için hazırlanmış özel WordPress temaları. Her tema **Görünüm > Özelleştir** üzerinden düzenlenebilir; kurulum için ilgili klasörü zip'leyip WordPress panelinden yükleyin.

## Temalar
- **kurumsal-pro** — kurumsal / genel işletme.
- **restoran-pro** — restoran / kafe.
- **saglik-pro** — sağlık / klinik.

Her klasörün içinde ayrıca `README.md` bulunur.
